1. Что это за документ

Это описание структуры сайта и пояснение к прототипу — черновой версии сайта для согласования с заказчиком до сборки на Tilda.

Прототип ≠ финальный сайт. Это макет логики, разделов и контента. Внешний вид на Tilda будет похож, но может отличаться по деталям (шрифты, отступы, анимации).

Вы получаете два отдельных standalone-файла — каждый открывается в браузере локально, без установки программ и без интернета.

Что в письме:

  • OPISANIE-PROTOTIPA.html — этот документ: структура сайта, пояснения, сравнение платформ
  • prototip-aleksandrovskaya.html — отдельное вложение: один файл, внутри всё (стили, скрипты, картинки). Папки и доп. файлы не нужны.

Как открыть прототип:

  1. Сохраните файл prototip-aleksandrovskaya.html на компьютер.
  2. Дважды щёлкните по нему — откроется в браузере (Chrome, Edge, Яндекс).
  3. Листайте страницу или пользуйтесь меню — все разделы на одном экране.
Прототип — один самодостаточный HTML-файл (~70 КБ). Работает без интернета. Сначала можно прочитать описание здесь, затем открыть прототип.

8.2. Какое фото считается качественным

Для сайта важны пиксели (ширина × высота), а не dpi из печати. Слишком маленькое фото на большом блоке выглядит мыльным. Современный смартфон обычно снимает 3000–4000 px — этого достаточно, если не сжимать файл в WhatsApp / Telegram.

ОценкаДлинная сторонаДля сайта
Слабоеменьше 1000 pxНе ставить на блоки
Среднее1200–1600 pxКарточки номеров, превью
Хорошее1920–2400 pxГлавный экран, галерея
Избыток4000 px и файл больше 8 МБМожно чуть уменьшить перед загрузкой

Фон главной (Ф1) — только горизонтальный кадр. Вертикальное фото на широкий блок обрежется (пол, кусок неба).

  • Формат: JPG для фото (вес ориентир 200 КБ – 2 МБ), PNG — только логотип.
  • Глазами: резкость, ровный горизонт, нормальный свет, один сюжет на кадр.
  • Не подходит: скрин из соцсети, 800×600, сжатая пересылка из мессенджера.
  • Как передать: оригиналы файлами, папки hero, номера, галерея, баня, территория. В имени файла укажите код: F1-hero.jpg, F8-odnomestny.jpg.
